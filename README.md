### 02. 실시간 패킷 관제 프로그램

> 네트워크 패킷을 실시간으로 수집하고 필요한 정보를 화면에 표시하는 데스크톱 프로그램

**Tech Stack**  
Java, JavaFX, JnetPcap

**담당 기능**

- 사용 가능한 네트워크 장치 조회 및 선택 기능 구현
- 송수신 패킷의 MAC, IP, Port 정보 추출
- 수집한 패킷 정보를 JavaFX 화면에 실시간으로 출력
- 선택한 패킷의 세부 정보 표시

**구현 흐름**

```text
네트워크 장치 선택 → 패킷 캡처 → 헤더 파싱 → 데이터 처리 → JavaFX UI 출력
```
